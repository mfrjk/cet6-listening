# 六级听力真题练习 · CET-6 Listening Practice

这是一个只练习英语六级听力的本地网页，包含真题练习、错题回顾和随机模拟练习。每套试卷按 A1–4、A5–8、B1、B2、C1、C2、C3 七个音频单元组织；模拟练习会从这些分段音频中随机组卷，保证 8、7、10 题，连续完成 25 题后按 249 分制统一评分。

## 当前题库

- 36 套试卷、252 组听力材料、900 道题。
- 2017–2022 年公开可核验的整套听力，以及 2026 年 6 月第 1、2 套已加入并切分。
- 2023–2025 年保留真题墙公开接口提供的分段任务，并按长对话、听力篇章、讲座 / 讲话组织。
- 2018 年 12 月第 1 套和 2019 年 6 月第 1 套因公开页面缺少完整题目或原文，未导入不完整数据。

旧年份与 2026 年新增试卷的题目、听力原文和音频已经按 Section A / B / C 拆分。音频使用 M4A 容器保存为独立文件，随机模拟会把抽中的分段音频拼接成一个连续音源。

听力原文支持逐句点击：点击某句会跳到对应时间点并继续播放，播放中的句子会自动高亮；练习时无需先选答案，点击音频下方的“显示 / 隐藏听力原文”即可打开醒目文稿；时间轴由多精度英文 Whisper 词级识别结果与原文逐词匹配，并对短句使用局部静音边界复核。全部 252 组、5730 句已完成音频范围、句数、顺序和来源检查；文稿已按音频时间排序，2021 年 12 月两套试卷的串套音频引用也已修复。

- 考试结构：[中国教育考试网](https://cet.neea.edu.cn/html1/folder/16113/1586-1.htm)。

## 使用

直接打开 `index.html`。如果浏览器限制本地音频播放，可以运行：

```text
node work/dev-server.cjs
```

然后访问 `http://127.0.0.1:4173/`。

本项目仅用于个人学习，请勿公开传播或用于商业用途。
